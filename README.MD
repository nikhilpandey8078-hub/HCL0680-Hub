Student Management System

Project Overview

The Student Management System is a Python-based application used to manage student records efficiently.

Developed By

Name: Nikhil Pandey

Technologies Used

- Python
- SQLite Database
- CSV
- Visual Studio Code

Features

1. Add Student
2. View Students
3. Search Student
4. Delete Student
5. Update Student
6. Store student records in SQLite database

Project Files

- "apps.py" – Main application
- "database.py" – Database operations
- "students_dataset.csv" – Student dataset
- "students.db" – SQLite database
- "SRS_Document.md" – SRS documentation
- "SRS_Document.pdf" – SRS PDF

How to Run the Project

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following commands in the terminal:

python database.py
python apps.py

5. Select an option from the menu.
