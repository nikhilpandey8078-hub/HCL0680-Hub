1. Introduction

The Student Management System is a Python-based application designed to manage student records efficiently. It allows users to add, view, search, update, and delete student information.

2. Purpose

The main purpose of this project is to reduce manual work and make student record management easier, faster, and more organized.

3. Scope

The system provides the following features:

- Add new student records.
- View all student records.
- Search students using roll numbers.
- Update student details.
- Delete student records.
- Store information in an SQLite database.

4. Technologies Used

Technology| Purpose
Python| Application development
SQLite| Database management
CSV| Dataset import
VS Code| Code editor
GitHub| Project hosting

5. Functional Requirements

1. Add Student: Add a new student's name, roll number, and course.
2. View Students: Display all available student records.
3. Search Student: Search for a student using their roll number.
4. Delete Student: Remove a student record using the roll number.
5. Update Student: Modify a student's name and course.
6. Database: Store student records permanently using SQLite.

6. Non-Functional Requirements

- The system should be easy to use.
- Student records should be stored securely in the database.
- The application should respond quickly.
- Duplicate roll numbers should not be accepted.
- The system should provide appropriate messages to users.

7. Database Design

Database Name: students.db

Table Name: students

Field| Description
id| Unique student ID
name| Student name
roll| Student roll number
course| Student course
email| Student email
phone| Student phone number
